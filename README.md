## Engineering Principles

**Define the problem before choosing the technology.**

구현할 기능을 늘리기 전에 해결해야 하는 문제와 우선순위를 먼저 정의합니다.

**Understand the trade-offs.**

기술 선택의 장점뿐 아니라 제약과 대안을 함께 고려합니다.

**Verify what I build.**

구현한 기능과 실제 검증한 결과를 구분하고, 재현 가능한 근거를 남기려고 합니다.
