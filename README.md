##  About Me

 >산업공학을 전공하며 시스템과 프로세스를 보는 눈을 키웠고, 이를 실제 소프트웨어로 구현하고 싶어 개발을 시작했습니다.

저는 단순히 코드를 작성하는 것보다 "이 기능이 사용자에게 왜 필요한가?"를 고민하는 시간을 좋아합니다. 흩어진 데이터를 모아 가공해서 유의미한 인사이트를 발견할 때, 그리고 그 결과가 실제 서비스로 동작할 때 성취감을 느낍니다.

현재는 **Spring과 Python**을 주력으로 사용하며, 최근에는 **AI를 접목한 개인화 서비스와 추천 시스템**을 깊이 있게 탐구하고 있습니다. 문제를 정의하고 해결하는 전체 프로세스를 설계하는 개발자입니다.
